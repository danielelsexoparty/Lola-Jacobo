Conexión y datos

¿Cómo conectar Firebase?
  1. Crea un proyecto en console.firebase.google.com y activa Firestore Database.
  2. En "Configuración del proyecto → Tus apps → Web" copia el objeto firebaseConfig.
  3. Pégalo en la constante firebaseConfig al inicio del <script type="module"> de este archivo.
  4. Colecciones usadas: premios, boletos y el documento config/ajustes.

Reglas sugeridas para empezar (ajústalas según tu seguridad):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /premios/{id}  { allow read: if true; allow write: if true; }
    match /boletos/{id}  { allow read: if true; allow create, update: if true; allow delete: if true; }
    match /config/{id}   { allow read: if true; allow write: if true; }
  }
}
